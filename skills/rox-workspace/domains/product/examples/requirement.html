Context

Owners can see that a run finished but not what each step received and returned, so they cannot tell why a result is wrong. Serves Tactic: Execution Trace, outcome "O1"; sprint Cycles/261012-trace-viewer.

Requirements

  1. R1 A finished run lists its steps in execution order, each with its status.
  2. R2 Selecting a step shows the input it received and the output it produced.
  3. R3 A payload over 64 KB is truncated and the view says so.

Acceptance criteria

  • Given a finished 3-step run, when the owner opens it, then 3 steps appear in order with their statuses.
  • Given a step with a 100 KB output, when the owner selects it, then 64 KB is shown with a truncation notice.

Out of scope

  • Editing a workflow from the trace view; runs that are still in progress.
